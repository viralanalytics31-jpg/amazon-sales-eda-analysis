# 📊 Amazon Sales EDA Analysis

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on an Amazon sales dataset to extract meaningful business insights.  
The analysis focuses on pricing trends, customer ratings, discounts, and product category performance.

---

## 🎯 Objectives
- Analyze pricing and discount patterns  
- Understand customer ratings and reviews  
- Identify top-performing product categories  
- Discover relationships between variables  
- Generate actionable business insights  

---

## 🛠️ Tech Stack
- Python 🐍  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook
  
---

## 📊 Key Analysis

### ✔ Data Cleaning
- Missing value handling  
- Duplicate removal  
- Data type correction  

### ✔ Exploratory Data Analysis
- Price distribution  
- Rating distribution  
- Discount vs Rating relationship  
- Category-wise performance  

### ✔ Data Visualization
- Histograms  
- Bar charts  
- Scatter plots  
- Correlation heatmap  

---

## 📈 Key Insights
- Higher discounts often lead to increased customer engagement  
- Some categories consistently outperform others in ratings  
- Product price does not always correlate with higher ratings  
- Popular products balance price, rating, and reviews
